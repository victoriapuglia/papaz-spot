# Papaz Spot Bar & Restaurant

One-page website for Papaz Spot, Lukuli Road, Makindye, Kampala. Static HTML/CSS/JS, served by GitHub Pages.

Facts were checked on 11 October 2026 against Google Maps, the venue's TikTok, Instagram and X profiles, and the Daily Monitor review of 4 May 2024. Food photography is illustrative and comes from Wikimedia Commons under CC BY-SA 4.0 (credits are on the page).
